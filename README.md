# Lexuria pin images

Eight Pinterest pin images for the free guide *10 Phone Settings That Make Life
Easier After 70*, published by Lexuria Publishing.

## Do not rename, move or delete any file in this repository

A scheduling tool fetches these images **at publish time**, not at the moment a
post is queued. A post scheduled for two weeks from now will reach for its image
on the day it publishes. Renaming or deleting a file here makes that post fail
silently: no error, no pin, and nobody finds out for a fortnight.

References to these files are pinned to a specific commit, so adding new images
later is safe. Removing or renaming an existing one is not.

## What belongs here

Pin images and nothing else. No credentials, no documents, no drafts, no PDFs,
no source templates, no personal information of any kind.
